# UI Guidelines & Aesthetic Identity

## 1. Aesthetic Identity
The AI Voice Business Card platform follows a minimal, high-tech, obsidian glass design language.

Key Visual Attributes:
1. **Subtle Glass Layers**: Semi-transparent panels layered over deep dark backgrounds (`#090d16`).
2. **Precision Borders**: Hairline 1px borders (`rgba(255,255,255,0.08)`) to structure elements cleanly without visual noise.
3. **Focused Accents**: Sky-blue accents used sparingly to highlight live voice activity and key CTA buttons.

## 2. Layout Principles
- **Public Voice Card**: Centered, single-column mobile-first container that feels like a physical digital twin card.
- **Admin Dashboard**: Fixed left navigation bar, persistent top header with company selector, and dynamic right-side content pane.

## 3. Micro-Interaction Rules
- Every interactive button must feature hover feedback (scaling `1.02` or brightness boost).
- Audio frequency waveforms must react smoothly to microphone input level changes.
- Loading states must utilize skeleton pulse blocks instead of layout-shifting spinners.
