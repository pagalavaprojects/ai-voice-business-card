# Responsive Strategy & Breakpoint Guidelines

## Breakpoint Map
- **Mobile (`<640px`)**: Single column stacked layout. Public card fills 100% width. Mic button sized `w-28 h-28`. Admin dashboard collapses left sidebar into a slide-over mobile drawer.
- **Tablet (`640px - 1024px`)**: Card constrained to `max-w-md`. Admin sidebar collapses to icon-only rail.
- **Desktop (`>1024px`)**: Admin dashboard shows full left navigation (`w-64`). Public card centered gracefully with glass background glows.

## Mobile Touch Optimization
- Touch targets for all voice call controls min `44px x 44px`.
- Mic button features touch haptic feedback hooks where supported.
