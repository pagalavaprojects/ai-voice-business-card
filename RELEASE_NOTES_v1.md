# AI Voice Business Card SaaS Platform v1.0 Release Notes

## Release Highlights:
- **Autonomous Digital Twin AI**: Powered by Vapi WebRTC streaming and GPT-4o-mini dynamic prompt assembly.
- **7 Native LLM Tools**: `save_lead`, `book_appointment`, `search_products`, `search_services`, `search_faqs`, `get_company_information`, `get_employee_information`.
- **Lead Qualification Engine**: Automatic score generation (`HIGH`/`MEDIUM`/`LOW`) based on budget, timeline, and need.
- **Glassmorphic SaaS UI**: Interactive voice card with Framer Motion pulse animations & complete Admin Dashboard with CSV Export.
- **Security & Hardening**: Supabase Auth SSR middleware, RBAC guards, Vapi HMAC signature checks, PostgreSQL RLS policies, production HTTP security headers, Docker multi-stage containers, and GitHub Actions CI.
