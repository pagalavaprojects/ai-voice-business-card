# AI Voice Business Card & Enterprise Platform Release Candidate v2.1

## Release Candidate Summary
Release Candidate v2.1 represents a fully hardened, multi-agent AI Employee Platform ready for commercial deployment.

- **Frontend Application**: Public Voice Card (`/[companyId]/[employeeId]`) & Admin SaaS Dashboard (`/dashboard`, `/dashboard/leads`, `/dashboard/agents`).
- **Backend Architecture**: Clean Architecture Domain Services, Supabase Repositories, Dynamic Prompt Assembly, Lead Qualification Engine, 7 Native LLM Tools, Multi-Agent Intent Router, and DAG Workflow Engine.
- **Security & Infrastructure**: Supabase Auth SSR Middleware, RBAC guards, Vapi HMAC signature verification, PostgreSQL RLS policies, Docker containerization, and GitHub Actions CI.
