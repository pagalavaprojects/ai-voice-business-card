# Role-Based Access Control (RBAC) Specification

## Roles & Permissions Matrix
- `SUPER_ADMIN`: All permissions (leads, knowledge, prompts, settings, user management).
- `COMPANY_ADMIN`: Company level administration.
- `MANAGER`: Write access to leads and knowledge base.
- `SALES`: Read/Write access to leads; Read access to knowledge.
- `SUPPORT` / `VIEWER`: Read-only access.
