# Enterprise AI Employee Platform v2.0 Release Notes

## Major v2.0 Platform Capabilities:
1. **Multi-Agent Fleet Orchestration**: Manage specialized AI agents across Sales, Technical Support, Recruiter, and Customer Success departments with automatic intent routing.
2. **DAG Workflow Automation Engine**: Visual DAG executor supporting triggers, logic branching, HTTP webhooks, Resend email dispatch, and Slack notifications.
3. **pgvector RAG Architecture**: PostgreSQL 1536-dimensional vector embedding search support (`rag_chunks` table).
4. **Model Context Protocol (MCP) Tool Registry**: Standardized tool interface supporting dynamic external tool discovery.
5. **AI Fleet Management Portal**: `/dashboard/agents` administration screen for configuring agent prompts, department routing, and capabilities.
